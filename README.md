# Astra Loader 3.3.1 — Windows-приложение

## Установить

Запустите **AstraLoader-Setup.exe**. Мастер на русском языке установит приложение по умолчанию в `%LocalAppData%\Programs\Astra Loader`, добавит пункт в меню «Пуск» и запись в «Параметры → Приложения → Установленные приложения». Можно выбрать ярлык рабочего стола и автозапуск только меню. Среда .NET включена в установщик.

Установка не удаляет Roblox и не включает блокировки. Обычный запуск открывает меню. Реальные операции запускает явно подписанная кнопка с запросом UAC. В меню «Пуск» также появляется отдельный ярлык безопасной проверки. Повторный запуск установщика обновляет существующую установленную копию. Перед установкой/обновлением закройте Astra Loader.

Требования: Windows x64, Windows 10 22H2 или новее. Стеклянный системный фон используется на поддерживаемых Windows 11; на других системах есть запасное оформление.

## Удалить

Откройте «Установленные приложения», выберите Astra Loader и нажмите «Удалить». Деинсталлятор предложит:

- **Да:** снять блокировки приложения, затем удалить его файлы и ярлыки. Для восстановления потребуется UAC. Если восстановление завершится ошибкой или повышение отменено, удаление остановится.
- **Нет:** удалить только программу; блокировки и данные восстановления останутся.
- **Отмена:** ничего не удалять.

Удаление убирает только запись автозапуска, указывающую на удаляемую установленную копию. Автозапуск другой переносимой копии не затрагивается. Папки с данными восстановления и прежними логами не удаляются. Удалённые ранее файлы Roblox не восстанавливаются.

Для автоматизированного удаления без диалогов применяется вариант восстановления перед удалением; повышение прав всё равно может потребовать подтверждения. Если нужны другие учётные данные, восстановление исходного профиля не выполняется: программа проверяет SID и отменяет операцию вместо работы с чужим профилем.

## Возможности

- Удаление известных процессов, папок, реестра Roblox и Store-пакета текущего пользователя.
- Блокировка установки через ACL, hosts и firewall для конкретных путей.
- Восстановление доступа, журнал, экспорт и проверка без изменений.
- Автозапуск меню и настройка анимаций окна.
- Liquid Glass стилизация, иконка, анимации, окно «О программе».

Приложение работает локально. Блокировки обратимы средствами Windows; защита от администратора не реализуется.

## Командная строка

```text
AstraLoader.exe --manual             открыть меню
AstraLoader.exe --dry-run            проверить план без изменений
AstraLoader.exe --run                запросить UAC и начать очистку
AstraLoader.exe --restore            открыть восстановление с UAC
AstraLoader.exe --restore-and-exit   восстановить доступ и вернуть код результата
AstraLoader.exe --startup-enable    зарегистрировать запуск только меню
AstraLoader.exe --startup-disable   удалить запись автозапуска приложения
AstraLoader.exe --startup-status    проверить регистрацию текущего EXE
```

`--restore-and-exit` используется деинсталлятором. Возвращает 0 только при успешном восстановлении, ненулевой код — при ошибке/отмене. Для тестирования поддерживается `--restore-and-exit --dry-run`. Параметр `--recovery-user <SID>` обеспечивает проверку профиля при повышении прав.

## Данные и совместимость

Данные восстановления хранятся отдельно от установки: `%ProgramData%\NL-Cleaner\<SID>`. Настройки анимаций: `HKCU\Software\NL-Cleaner\Preferences`. Эти технические адреса старых версий сохранены для совместимости. Идентификаторы прежних hosts/firewall блоков также сохранены для восстановления.

Автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `Astra Loader`, команда `"<путь>\AstraLoader.exe" --manual`. Windows может отключить запуск своими настройками; приложение не обходит их и не восстанавливает запись самостоятельно.

## Собрать приложение и установщик

Нужны .NET 10 SDK и [Inno Setup 6.7+](https://jrsoftware.org/isdl.php).

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1
```

Результат: `dist\AstraLoader-Setup.exe`. Промежуточные файлы находятся в `work\installer-build`. Можно указать `-DotnetPath`, `-IsccPath`, `-BuildRoot`, `-OutputDirectory`. `-OfflineBuild` использует доступные локально пакеты без проверки NuGet audit по сети.

Только переносимая сборка:

```powershell
dotnet publish .\AstraLoader.csproj -c Release -r win-x64 --self-contained true -o .\publish
```

## Подпись

Пересобранные файлы по умолчанию не подписаны. Для подписи приложения **до упаковки** и готового установщика выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1 -Sign -CertificateDirectory 'C:\путь\к\certificates'
```

Скрипт попросит пароль PFX. Используйте прежний пароль для существующего `Neverlose-fixed.pfx`; при отсутствии PFX будет создан новый самоподписанный сертификат `CN=Neverlose fixed`. Имя сертификата не связано с названием приложения и не устанавливает доверие публичного CA. Trust stores не изменяются. Генерируемый Inno-деинсталлятор отдельно не подписывается этим режимом.

Подписать только готовый установщик:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\sign.ps1 -PublishDirectory 'C:\папка\с\установщиком' -FileNames AstraLoader-Setup.exe -CertificateDirectory 'C:\путь\к\certificates'
```

Архив исходников и установщик не содержат PFX, паролей или приватных ключей.

## Проверено

Release-сборка и компиляция Inno Setup. Мастер проверен до страницы готовности к установке и закрыт без установки. Проверены безопасное восстановление с завершением процесса и отклонение чужого SID, а также анимации и компоновка интерфейса в dry-run. Установка, реальное снятие блокировок и полное удаление на рабочем ПК в проверку не входили.

```powershell
dotnet run --project .\tests\Startup\Startup.Tests.csproj -c Release
dotnet run --project .\tests\NL-Cleaner.Tests.csproj -c Release
```

Системные тесты junction и Firewall COM могут требовать доступа вне ограниченной среды. Исходный скрипт установки: `installer\AstraLoader.iss`.

## Приватность сборки
Release не создаёт PDB и использует PathMap для путей компиляции. Сборщик установщика автоматически проверяет EXE/DLL на личные пути Windows и путь проекта. Проверку можно запустить отдельно: `powershell.exe -File .\installer\verify-privacy.ps1 -PublishDirectory .\publish`. Профиль и пути журналов приложения определяются во время запуска на компьютере пользователя.
